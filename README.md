Dashboard and Datasource specification
======================================

This repository contains the specifications for the Perses dashboard and datasource formats. These specifications are
provided in different languages to facilitate their use in various contexts.

As Perses has a plugin oriented architecture, these specifications are partial as they only cover the core features of
the dashboard and datasource formats. Plugin authors are expected to extend these specifications with their own custom
fields as needed.

See the [plugins repository](https://github.com/perses/plugins) if you would like to see the different plugins provided
by the Perses team and the community.
